# 判断题补题说明（附件 3 缺判断题练习题）

## 为什么补

附件 3《复习指导（第六版）》开头的「考试形式与试题结构」写得明白：满分 100 分，
包括**填空题、选择题（单选 / 多选）、判断题、简答题和论述题**。

但后面的「理论考试试题参考汇编」只有四个小节（填空 / 选择 / 简答 / 论述），
一道判断题练习都没有。于是这个题库里判断题是 0 道，模拟考试也配不出判断题。

## 怎么做

从附件 3 里已有的原题**改写**成判断题，不引入附件 3 之外的新知识点：

- 48 个考点各 1 道，共 48 道；
- 答案「正确」24 道、「错误」24 道，一半一半，不能靠猜「都是对的」蒙分；
- 判「错误」的命题都只动**一个关键要素**——年份、主体、次序、范围、归属，
  语句本身通顺，错得明确、可复核，不做「半对半错」的模糊表述；
- 每题带 `source` 字段，写清改编自附件 3 哪一页、哪一节的第几题，
  方便回头对照原文。

例题形态（以下不是题库原文，只示意两种写法）：

| 答案 | 写法 |
| --- | --- |
| 正确 | 照原题的正确答案陈述一遍 |
| 错误 | 把原题里的一个关键要素换掉（年份、主体、纪律种类、先后次序等） |

## 数据侧

- 题库：337 → **385** 题（判断题 48 道，`section: "judge"` / `sectionLabel: "判断题"`）；
- 重点题：178 道（判断题全部挂了考点，48 个考点没有一个空着）；
- `meta.counters` 里多出 `"judge": 48`，考点 `count` 全部重算。

## 顺带修的「词面挂靠」

判断题补完之后，又回头修了考点匹配的一个老毛病：**干扰项也在参与关键词匹配**。

原来把选择题四个选项的文字全拼进语料，于是

- 问「最大政治优势」的题，C 项写着「坚持民主集中制」，就被挂到「党内民主」；
- 问「新民主主义革命胜利标志」的题，A 项写着「红军长征的胜利」，就被挂到「长征」。

现在只有**正确答案对应的选项**才算语料（题干、材料、答案照旧）。用同一份 `data/keypoints.json`
重标后，27 道原书题的挂靠发生变化，其中 6 道直接掉出「重点题」——它们本来就是被干扰项带进去的。
重点题 195 → 178。

`k25`（关于经济体制改革的指导方针）原来只有一道靠干扰项挂上的题，重标后原书题清零，
由本次补的判断题顶上，现在这个考点至少有 1 道直接相关的题。

## 脚本

补题与重标脚本在本地 `.shots/`（不进仓库、随 `.gitignore`）：

- `.shots/_add_judge.mjs`：写入 48 道判断题（幂等，重跑先清旧判断再重建），重算 `meta` 与考点 `count`；
- `.shots/_retag.py`：用「干扰项不算」的口径重标原书题；带 `source` 的补题与判断题保留人工标注。
  不加 `--apply` 只打印差异。

## 校验

- `npm run verify`：typecheck + 63 项单元测试 + build + 发布守卫，全绿；
- 数据集检查：385 题、无重复 `id`、无悬挂考点引用、48 考点均非空、判断题对错 24 / 24；
- 走查（Edge headless + CDP）：判断题练习页两个按钮、提交后给「答对 / 答错 + 正确答案」、
  题库页「判断」筛选出 48 道、背题页有【判断题】小节且答案行是「正确 / 错误」。
