# 多选题扩充说明（2026-11-01）

## 为什么做

题库原来只有 **1 道多选**（2026 全国两会议程），可结业考试里多选是固定题型，刷题时这一块几乎是空的。这次把题库里**能自然出成多选题**的知识点扩成一批多选，全部挂考点、进重点池。

## 怎么做

- 范围：48 个考点里的知识点，按「以下属于／包括 X 的有（）」的方式改编，共 **50 道，覆盖 46 个考点**（k19 三个务必、k44 青年成长已有其他形式的题，不重复）。
- **正确选项全部取自题库已确认的标准答案**——填空题的答案、简答题的要点原文、判断题判为「正确」的表述，没有一条是新编的。
- **干扰项一律取自别的知识点**，并优先用题库里已经被判错的表述：比如三大优良作风的干扰项用「勤俭节约」（对应判断题 Q0340 判错）、六大纪律的干扰项用「学习纪律」（Q0384 判错）、共青团的干扰项用「党中央的直属工作部门」（Q0380 判错）。
- 题干不写题型提示，由 `type: multi` 决定；答案按字母串（如 `ABC`）。
